## The Story — V1 → V2 → V3

### Version 1 — POW Only
The original Waya Wolf Coin was pure proof-of-work. Two critical flaws: a **51% attack vector** where a miner could dominate the chain, and **chain stalls** when no one was mining. Keeping the chain alive required significant personal expense.

### Version 2 — POW + POS
Version 2 added proof-of-stake, solving both the 51% attack and the stalled-chain problem. But it inherited an **unstable codebase**, and its **scrypt-based POW** locked out anyone without dedicated GPU/ASIC hardware.

### Version 3 — POW + POS Hybrid
Version 3 retains the proven POW + POS hybrid model while delivering a **hardened, more stable codebase** with additional exploit mitigations. The **HMQ1725 algorithm** makes true **CPU mining** possible — anyone with a processor can mine via pool or solo. Combined with the chain stability of proof-of-stake, WW V3 is accessible, resilient, and built for the long haul.

> *"Thus, anyone could mine the coin."* — WayaWolf
