Release Process
===============

Pre-built binaries for Linux (64-bit) and Windows (32/64-bit) are distributed
via GitHub Releases:

  https://github.com/Waya-Wolf/WWC3/releases

To create a new release:

1. Update VERSION in src/clientversion.h (CLIENT_VERSION_* macros)
2. Update VERSION in wayawolfcoin.pro
3. Update version strings in doc/README and doc/README_windows.txt
4. Commit changes and tag the release, e.g.:
     git tag -a 1.1 -m "v1.1"
5. Build binaries inside Docker on Ubuntu 16.04 (see release 1.0 for reference)
6. Upload archives and .sha256 checksums to GitHub Releases
7. Update the website (https://wayawolfcoin.com) with new download links
