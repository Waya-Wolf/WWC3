DOCKER BUILD
============

The easiest way to build Wayawolfcoin from source is with Docker.
No toolchain setup is needed.  The script handles everything inside
a clean Ubuntu 16.04 environment that matches the original release.

Prerequisites
-------------

Install Docker: https://docs.docker.com/engine/install/

Usage
-----

  cd share/
  ./build-docker.sh [version]

The build produces a headless daemon (wayawolfcoind) and a Qt GUI
(Wayawolfcoin-qt).  Both are statically linked against Qt5.

Output
------

Binaries and archives are written to /tmp/wwc3-v<version>/.

  /tmp/wwc3-v1.0.0/
    wayawolfcoind-linux-x86_64
    Wayawolfcoin-qt-linux-x86_64
    wayawolfcoind-linux-x86_64.tar.gz
    Wayawolfcoin-qt-linux-x86_64.tar.gz
    SHA256SUMS

Artifacts are not tracked by git.  They live outside the repository
so the working tree stays clean.

Notes
-----

The build uses the same GCC 4.9.0, OpenSSL 1.0.2g, Berkeley DB 4.8.30.NC,
Boost 1.58.0, and miniupnpc 1.6 toolchain as the original release,
ensuring bit-identical behavior.
